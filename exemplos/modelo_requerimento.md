# Modelo do requerimento (Google Docs)

Crie um Google Docs com o conteúdo abaixo. A formatação aplicada a cada marcador (negrito, fonte, tamanho) é mantida no texto que o substitui.

Os marcadores devem ser escritos exatamente assim, com chaves duplas e em maiúsculas: o nó do Google Docs usa **Find and Replace Text** com *Match Case* ligado.

```
{{NOME_SERVICO}}

O que é: {{DESCRICAO}}

Quem pode solicitar: {{PUBLICO}}

Documentos necessários: {{DOCUMENTOS}}

Etapas: {{ETAPAS}}

Prazo para atendimento: {{PRAZO}}

Custo: {{CUSTO}}

Como e onde solicitar: {{COMO_SOLICITAR}}

Setor responsável: {{SETOR}}
```

Os campos seguem o art. 7º, § 2º, da Lei nº 13.460/2017 (Código de Defesa do Usuário do Serviço Público).
